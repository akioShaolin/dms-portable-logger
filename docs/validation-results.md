# Resultados de validação

Builds PlatformIO e testes native executados localmente estão documentados em `docs/testing.md`. Ferramentas Python possuem testes de COBS/CRC, JBD length-driven, CSV físico, arquivo sintético truncado e preservação hexadecimal de registros desconhecidos.

Testes com BMS, dois ED100, painel e moto permanecem pendentes. Nenhum resultado físico foi inferido a partir de compilação ou simulação.
